# Внедрение DevSecOps-практик

В проекте реализована демонстрационная информационная система на основе Django и PostgreSQL. Для повышения уровня защищённости жизненного цикла разработки и эксплуатации были внедрены практики DevSecOps.

DevSecOps означает, что безопасность не выносится в отдельный финальный этап, а встраивается во все стадии жизненного цикла: проектирование, разработку, тестирование, сборку, поставку и эксплуатацию.

В проекте реализованы следующие элементы:

1. Контейнеризация приложения с помощью Docker.
2. Описание инфраструктуры через docker-compose.yml.
3. Автоматический запуск базы данных PostgreSQL.
4. Автоматическое применение миграций Django при старте контейнера.
5. Health-check endpoint для проверки состояния приложения.
6. Security middleware для регистрации событий безопасности.
7. Безопасные настройки Django: HTTPOnly cookie, защита от clickjacking, запрет MIME sniffing, HSTS для production-режима.
8. CI/CD pipeline на GitHub Actions.
9. Статический анализ безопасности через Bandit и CodeQL.
10. Проверка зависимостей через pip-audit.
11. Поиск секретов через Gitleaks.
12. Сканирование Docker-образа через Trivy.
13. Динамическое тестирование работающего приложения через OWASP ZAP.
